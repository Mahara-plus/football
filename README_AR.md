# Football Challenge — المرحلة الثانية (Starter)

هذه حزمة مصدر أولية قابلة للتطوير، وليست APK جاهزاً ولا خدمة إنتاجية تستوعب 100 ألف لاعب بعد.

## ماذا تحتوي؟
- تطبيق Android بسيط (WebView) يفتح واجهة اللعبة المرفقة.
- خادم Node.js + Socket.IO للغرف والمباريات المتزامنة.
- تسجيل حسابات بالبريد وكلمة المرور باستخدام PostgreSQL و bcrypt و JWT.
- إعداد عدد الجولات، وعدد اللاعبين الأقصى، ووقت السؤال.
- أقسام: انتقالات، معلومات عامة، أو مختلط.
- أسئلة تجريبية قابلة للإضافة والتعديل.
- لوحة نقاط مباشرة داخل الغرفة.

## تشغيل الخادم محلياً
1. ثبّت Node.js 20 أو أحدث و PostgreSQL.
2. أنشئ قاعدة بيانات باسم `football_challenge`.
3. نفّذ ملف `server/schema.sql` على قاعدة البيانات.
4. انسخ `server/.env.example` إلى `server/.env` وعدّل بيانات PostgreSQL وغيّر JWT_SECRET.
5. من مجلد `server` نفّذ:
   `npm install`
   `npm start`
6. افتح `http://localhost:3000` في المتصفح.

## تشغيل تطبيق Android
- افتح مجلد `android` في Android Studio.
- عدّل عنوان الخادم في `android/app/src/main/assets/config.js`.
- للمحاكي استخدم `http://10.0.2.2:3000`.
- للهاتف الحقيقي استخدم عنوان HTTPS عام للخادم أو عنوان IP محلي للهاتف والخادم على الشبكة نفسها.
- شغّل التطبيق من Android Studio، أو اختر Build > Build APK(s).

## ملاحظات مهمة
- إعدادات عدد اللاعبين في هذه النسخة هي حد أقصى للغرفة، وليست ضماناً لعدد ضخم من الاتصالات.
- النسخة الحالية تستخدم ذاكرة الخادم لإدارة الغرف؛ إذا أُعيد تشغيل الخادم تُغلق الغرف النشطة.
- قبل الإطلاق العام يجب إضافة Redis adapter لتوزيع Socket.IO، تخزين حالة المباريات، مراقبة، حماية إساءة الاستخدام، واختبارات ضغط تدريجية.
- لا تضع مفاتيح أو كلمات مرور حقيقية في ملفات المشروع.
